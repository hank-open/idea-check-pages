#21.1 L1：基于净值的回归归因

#单因子模型（第 2 章方法 B 的扩展）

α\alphaα 的解读（这是最重要的）：

α年化≈c⋅L⏟票息+骑乘⏟小+择券⏟？−(L−1)rrepo⏟融资−f⏟费用\alpha_{\text{年化}} \approx \underbrace{c \cdot L}_{\text{票息}} + \underbrace{\text{骑乘}}_{\text{小}} + \underbrace{\text{择券}}_{\text{？}} - \underbrace{(L-1)r_{\text{repo}}}_{\text{融资}} - \underbrace{f}_{\text{费用}}α年化​≈票息c⋅L​​+小骑乘​​+？择券​​−融资(L−1)rrepo​​​−费用f​​

所以 α\alphaα 不是"管理能力"，它主要是票息。 这是债基归因最容易误解的地方：

在股票基金里，α\alphaα ≈ 选股能力。 在债券基金里，α\alphaα ≈ 票息水平 − 费用，而票息水平主要来自信用下沉和杠杆。

所以高 α\alphaα 的债基，很可能只是下沉更深、杠杆更高，不是管理能力更强。

#怎么从 α 里剥出真正的能力

真实能力=α实际−α结构性应得\text{真实能力} = \alpha_{\text{实际}} - \alpha_{\text{结构性应得}}真实能力=α实际​−α结构性应得​ α结构性应得=c^⋅L^−(L^−1)rrepo‾−f\alpha_{\text{结构性应得}} = \hat{c} \cdot \hat{L} - (\hat{L}-1)\overline{r_{\text{repo}}} - fα结构性应得​=c^⋅L^−(L^−1)rrepo​​−f

其中 c^\hat{c}c^ 和 L^\hat{L}L^ 从季报估算（第 7、9、12 章）。

#从这张表读出的四件事 ★

#① 收益结构的稳定性

票息占比在 8 个季度中稳定在 60–80%   → 票息型，收益可预测
票息占比在 20%–150% 之间大幅波动     → 久期型，收益靠方向判断

#② 久期判断的胜率

久期择时胜率=② 利率项为正的季度数8\text{久期择时胜率} = \frac{\text{② 利率项为正的季度数}}{8}久期择时胜率=8② 利率项为正的季度数​
胜率解读
> 70%可能有真实的久期择时能力 ★
50–70%正常（和市场方向一致）
< 50%久期择时在毁灭价值

但要小心：如果这 8 个季度债市整体是牛市，那么"持续正的利率项"只说明它一直保持着高久期，不说明它会择时。

修正方法：和同类平均对比。

久期择时 alpha=② 利率项−D同类‾×(−Δy)\text{久期择时 alpha} = \text{② 利率项} - \overline{D_{\text{同类}}} \times (-\Delta y)久期择时 alpha=② 利率项−D同类​​×(−Δy)

即：扣除"维持类别平均久期本来就能拿到的部分"，剩下的才是择时。

#③ 下沉的净收益

下沉的净贡献=(票息溢价)⏟①中的一部分+③ 利差损益⏟代价\text{下沉的净贡献} = \underbrace{(\text{票息溢价})}_{\text{①中的一部分}} + \underbrace{\text{③ 利差损益}}_{\text{代价}}下沉的净贡献=①中的一部分(票息溢价)​​+代价③ 利差损益​​

计算方法：

票息溢价 = (组合票息 c) − (同期限国开债收益率)
         ← 这是下沉 + 二永 + 期限溢价带来的额外票息

利差损益 = −D_spread × Δs
         ← 这是下沉的代价

8 期合计看：

情形推断
票息溢价累计 > |利差损益累计|下沉是赚钱的（在这个区间）
票息溢价累计 < |利差损益累计|下沉是亏钱的

关键提醒：

在利差收窄的年份，下沉必然赚钱（票息溢价 + 利差收窄的资本利得双赢）。 在利差走阔的年份，下沉必然亏钱，而且亏得很快。

所以"下沉赚了多少"必须看完整周期，至少包含一次利差走阔。 只看牛市区间的下沉收益，是在用运气冒充能力。

#④ 杠杆的净收益

杠杆净贡献=(L−1)(c−rrepo)⏟carry 差+(L−1)(−D持仓Δy)⏟放大\text{杠杆净贡献} = \underbrace{(L-1)(c - r_{\text{repo}})}_{\text{carry 差}} + \underbrace{(L-1)(-D_{\text{持仓}}\Delta y)}_{\text{放大}}杠杆净贡献=carry 差(L−1)(c−rrepo​)​​+放大(L−1)(−D持仓​Δy)​​

8 期合计，然后对比：

杠杆的风险增量=(L‾−1)×D持仓‾×σΔy\text{杠杆的风险增量} = (\overline{L} - 1) \times \overline{D_{\text{持仓}}} \times \sigma_{\Delta y}杠杆的风险增量=(L−1)×D持仓​​×σΔy​

算出"杠杆的收益/风险比"，和"不加杠杆的收益/风险比"对比。

典型结论（第 9 章已预告）：

在利差压缩环境下，杠杆的收益风险比很差。 它贡献几十 bp 的收益，放大 20–30% 的风险。

#发现一：真实票息 = 2.76%

不用估算了。 这个数可以用来校准你用第 7 章方法 B/C 估出来的 c^\hat{c}c^。

注意：债券利息收入 / 平均净值 = 2.76%，这已经包含了杠杆（因为杠杆买的债也在产生利息）。所以：

c×L=2.76%⇒c=2.76%Lc \times L = 2.76\% \quad\Rightarrow\quad c = \frac{2.76\%}{L}c×L=2.76%⇒c=L2.76%​

若 L=1.22L = 1.22L=1.22，则 c=2.26%c = 2.26\%c=2.26%。

#发现二：杠杆成本 = 0.62%（占净值）★

杠杆成本率=利息支出平均借入资金=3,100500,000×0.22=3,100110,000=2.82%\text{杠杆成本率} = \frac{\text{利息支出}}{\text{平均借入资金}} = \frac{3,100}{500,000 \times 0.22} = \frac{3,100}{110,000} = \mathbf{2.82\%}杠杆成本率=平均借入资金利息支出​=500,000×0.223,100​=110,0003,100​=2.82%

等一下，这个数太高了。 如果同期 R007 均值是 1.75%，2.82% 的融资成本意味着什么？

三种可能：

  1. 杠杆率实际比 1.22 更低（平均借入资金更少，所以除下来率更高）
  2. 这只基金的融资能力差（第 9 章的"杠杆成本"指标）
  3. 利息支出里还包含其他项（如融券成本）

这个矛盾本身就是一个发现，需要进一步核查。这正是财报归因的价值：它会暴露你估算中的错误。

假设实际平均杠杆率是 1.35（季报的期末值 1.22 低估了期间平均值）： 3,100500,000×0.35=3,100175,000=1.77%\frac{3,100}{500,000 \times 0.35} = \frac{3,100}{175,000} = 1.77\%500,000×0.353,100​=175,0003,100​=1.77% 这就和 R007 均值 1.75% 吻合了。 所以真正的发现是：这只基金的期间平均杠杆率显著高于季报期末值。

这是一个极其重要的技术：季报期末杠杆率可能被"美化"（季末降杠杆，季初加回来）。 用财报的利息支出反推期间平均杠杆率，可以揭穿这种"窗口粉饰"。

#发现三：已实现价差是 −0.37%（亏的）★

它在交易上是亏钱的。 这意味着：

  • 它卖出的债券是亏损卖出（可能被赎回逼的）
  • 或者它的交易择时能力为负

而公允价值变动是 +1.28%（赚的），说明剩余持仓有浮盈。

组合判断：

已实现亏 0.37% + 浮盈赚 1.28% = 净资本利得 +0.91%
                                   ↓
对比：如果用久期估算，D_net × (-Δy) 应该是多少？
      若 D_net = 3.0，年内 Δy = −30bp → 应该是 +0.90%
      
★ 吻合（0.91% vs 0.90%）→ 归因自洽

但结构有问题：它本应该赚 0.90%，结果是"浮盈 1.28% − 已实现亏 0.37%"
            → 说明它在不该卖的时候卖了，损失了 0.37%
            → 这是 37bp 的交易损耗（被动或主动）

这 37bp 的发现，只有财报归因能做到。 净值数据和季报都看不出来。

#发现四：交易费用只有 0.056%，但真实交易成本更高

交易费用科目不含银行间市场的买卖点差（第 11 章）。真实交易成本 = 交易费用 + 点差损耗，而点差损耗部分体现在"债券投资收益"里。

所以上面那 −0.37% 的已实现亏损里，有一部分就是点差。

#发现五：费用合计 = 0.30 + 0.075 + 0.056 + 0.019 = 0.45%

和招募说明书的 0.40%（管理费+托管费）对比，多出 0.05% 是交易费用和其他费用。

#重点展开：④ 风险个券识别的两个方法 ★

#方法 A：重仓券观察法

① 从季报取前五大重仓券（第 12 章）
② 对每只券查：
   - 中债隐含评级 及其变动历史
   - 发行人的负面舆情（关联方违约、评级下调、监管处罚）
   - 该券的二级成交价 vs 中债估值的偏离
③ 标记所有"隐含评级低于外部评级两档以上"的券
④ 跨期跟踪：某只有问题的券是否持续在重仓名单里

局限：只能看到前五大，覆盖率低（第 12 章的红线）。

#方法 B：净值异动法 ★★

这个方法可以绕过披露限制，发现"你看不到的持仓里"的问题。

原理：如果某只持仓券的估值被大幅下调，基金净值会出现
      "无法被利率和利差解释的"单日异常下跌。

做法：
① 用多因子模型（21.1 节）算出每日的预测收益率
② 算残差：ε_t = 实际收益率 − 预测收益率
③ 标记所有 |ε_t| > 3σ(ε) 的日子           ← 异动日
④ 对每个异动日，检查当天的债市新闻：
   - 有没有某个发行人出事？
   - 有没有某只债券被下调估值？
⑤ 如果能对应上，说明这只基金持有该发行人的债 ★
   —— 即使它从未出现在前五大重仓名单里

这是一个"用净值反推隐形持仓"的技术。 它的威力在于：

你不需要知道基金持有什么，只需要观察它在某只债券出事那天跌了多少。

实操示例：

某日：X 公司债券被曝负面，中债大幅下调其估值
      当天中债 3Y 国债 −1bp，AAA 利差 +1bp（市场平静）
      
基金 A 当日 −0.02%（符合预测）        → 大概率没持有 X
基金 B 当日 −0.31%（残差 −0.28%，6σ）→ ★ 大概率持有 X，且占比不小
       
估算占比：若 X 债券估值被下调 8%，则
         基金 B 的 X 持仓占比 ≈ 0.28% / 8% = 3.5%

这个方法在 2020 年永煤违约、2021 年地产债违约期间被广泛使用，可以在基金披露之前就识别出风险暴露。

建议：把它做成一个常设流程：

每天算一次残差
残差超过 3σ 时，自动触发人工核查
把核查结果记入基金档案（第 28 章）

  6. 这是一个 5σ 的净值异动，几乎必然是某只持仓券的估值被大幅下调（净值异动法）。 立即行动： （a）查当天的债市新闻和公告：有没有发行人违约、评级下调、负面舆情、监管处罚、永续债不赎回？ （b）查中债当天的估值调整公告：哪些券被大幅下调？ （c）估算暴露占比：若某券估值被下调 X%，则持仓占比 ≈ 0.42% / X%。例如下调 10% → 占比约 4.2%； （d）交叉验证：看同类其他基金当天的残差——如果多只基金同时异动，说明是一个被广泛持有的券；如果只有这一只，说明是它的特色持仓； （e）查最近的季报重仓券：如果该发行人在前五大里，确认；如果不在，说明它藏在未披露的 95% 持仓里，这本身是更严重的发现（披露覆盖率问题）； （f）决策：如果确认持有问题券且占比 > 3%，考虑减仓。记入基金档案并持续跟踪该发行人的后续处置。
  7. 买 B。 理由（三层）： （a）A 的收益来源不可持续：4.5% 里有 3.0%（67%）来自利率下行。这是一次方向押注的结果。如果下一年利率反转 30bp，它会亏约 3%，加上票息也只能勉强打平甚至为负。 （b）A 没有真实能力：残差 α = −0.2%，说明扣除结构性应得（票息 + 杠杆）后，它的管理是负贡献的。它的高收益完全来自"承担了更多久期风险"，而不是"管得更好"。 （c）B 有真实能力：残差 α = +0.6%，是实实在在的超额。它的收益主要来自票息（可持续），利率项只贡献 0.8%（久期适中）。 额外的结构推论：A 的隐含久期必然远高于类别均值（才能赚到 3.0% 的利率项），所以它的回撤风险、修复天数、P(1M) 都显著更差（第 19、20 章）。 决策逻辑的要点：买 A 等于在押注利率方向（而且是在押别人的判断）；买 B 等于在购买管理能力。 如果你自己对利率方向有强判断，更好的做法是直接买长久期利率债指数基金（更便宜、更纯粹），而不是通过 A 间接表达。
